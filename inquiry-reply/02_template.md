# 問い合わせ返信の依頼の型（下書き＋レビュー＋改訂）

「下書き → 指摘だけのチェック → 1回だけ修正」を1回の依頼で済ませるための型です。【】の部分を差し替えて、そのまま貼り付けて使います。

```
次の問い合わせへの返信を作ってください。手順は①〜③の順に、それぞれ分けて出してください。

――問い合わせ本文――
【ここに問い合わせを貼る（氏名・連絡先・診療内容などの個人情報は伏せて〇〇に置き換える）】
――――――――――

■前提
・文体：【丁寧語／です・ます調】
・送信経路：【メール／LINE／フォーム返信／不明】（不明なら、どの経路でも使える形に）
・参考にしてよい情報：【院の公式情報・FAQなどがあれば貼る／なければ「なし」】

■作成ルール
・分かる範囲で答え、こちらで確認が要る点は「確認のうえ、改めてご連絡いたします」にする
・上記の参考情報にない事実（日付・料金・空き状況・院のルールなど）は書かず、決めつけない
・回答期限・返信方法・院名・担当者名など、こちらで埋める箇所は【】で残す
・治療の効果や安全性には触れない

① 下書き
上の条件で返信文を作る。

② チェック（直さず、指摘だけ）
次の観点で①を見直し、問題点を挙げる。
・聞かれたことに漏れなく答えているか（質問を1つずつ分けて確認する。まとめて答えて片方が抜けたように見えないか）
・「追って」の期限や返信方法など、相手が次に何をすればよいかが分かるか
・こちらで勝手に決めつけた事実はないか（日付・料金・空き状況・システムの仕様・送信経路など）
・敬語や言い回しに不自然さはないか（電話向けの言い方をメールで使っていないか、同じ言い回しの繰り返し、二重敬語、締めの言葉がちぐはぐでないか）
・送信経路に合った形式か（Markdownの記号がそのまま表示されないか）

③ 修正版（1回だけ）
②の指摘をすべて反映した最終版を出す。あわせて、
・直したところ（箇条書きで短く）
・送る前に埋める【】の一覧
を出す。
```

## 使うときのコツ
- 「参考にしてよい情報」が一番大事です。院の持ち物・所要時間・支払い方法などを貼っておけば、「追ってご連絡」ばかりの返信にならず、具体的に答えられます。
- 患者さんの個人情報はチャットに入力しないでください。問い合わせを貼る前に、氏名や連絡先などは〇〇に置き換えます。
- ③の修正版も、AIが一次的に作った下書きです。送信前に必ず担当者が確認してください。
